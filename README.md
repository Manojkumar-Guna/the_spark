# The Spark Multi-Sports Arena website

Static website. No build step or installs needed.

## Run locally
1. Open this folder in VS Code (File > Open Folder).
2. Install the "Live Server" extension when VS Code suggests it.
3. Right-click `index.html` > "Open with Live Server".

## Folder layout
- `index.html`  page content (text, phone numbers, price, address, map link)
- `css/style.css`  colours, fonts, layout
- `images/`  logo and photos (replace a file, keep its name)

## Common edits
- Phone numbers: search `tel:` and `94863` / `96290` in index.html
- WhatsApp number: search `wa.me`
- Price and offer: search `Starting from` and `Offer on now`
- Map link: search `maps.app.goo.gl`
- Colours: the `:root` block at the top of css/style.css

## Host
Upload the whole folder (keep the structure) to Netlify, Cloudflare Pages, GitHub Pages or any web host.
